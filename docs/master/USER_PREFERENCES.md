# USER_PREFERENCES — tc-gaming.live

## 1. PHONG CÁCH LÀM VIỆC (Working Style)
- **Tốc độ:** Ưu tiên tính ổn định (Stability) hơn là tốc độ triển khai nhanh (Speed). 
- **Giao tiếp:** Ngắn gọn, súc tích. Chỉ báo cáo các mốc quan trọng.
- **Phong cách Code:** Chuẩn Monorepo, Domain-Driven, đề cao tính type-safe (TypeScript).
- **Mức độ kiểm soát:** Tôi muốn bạn chủ động làm hết, chỉ cần báo cáo kết quả cuối cùng.

## 2. MỤC TIÊU CỐT LÕI (Core Goals)
- Ổn định Production (Zero Downtime).
- Code phải sạch, dễ bảo trì, test được.
- Tận dụng tối đa các công cụ miễn phí để giảm tải VPS.
