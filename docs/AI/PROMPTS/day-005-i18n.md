## Bước 7 — Cleanup `libs.old-root/`

```bash
ls /var/app/game/libs.old-root/
```

Nếu chỉ chứa `i18n/` cũ và nội dung đã được migrate vào `libs/i18n/` → xóa:

```bash

```

Xóa `.backup-roots/` nếu empty:
```bash
ls /var/app/game/.backup-roots/ && rmdir /var/app/game/.backup-roots/ 2>/dev/null || echo "Not empty, keep"
```
