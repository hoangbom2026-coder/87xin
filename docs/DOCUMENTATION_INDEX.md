# DOCUMENTATION_INDEX

## 1. MỤC TIÊU
Bộ tài liệu này là "nguồn sự thật duy nhất" (Source of Truth) cho dự án tc-gaming.live.

## 2. CẤU TRÚC
- `01-codebase/`: Quy tắc import, chuẩn code, cấu trúc thư mục.
- `02-architecture/`: Nguyên lý monorepo, luồng dữ liệu (Dependency Graph).
- `03-applications/`: Chi tiết kỹ thuật của từng app (`apps/`).
- `04-libraries/`: Chi tiết các thư viện dùng chung (`libs/`).
- `07-domain/`: Logic nghiệp vụ (VIP, Affiliate, Game Wallet).
- `99-reports/`: Audit, kỹ thuật, tình trạng lỗi.

## 3. CÁCH SỬ DỤNG
Mọi thay đổi kiến trúc PHẢI cập nhật vào file tương ứng trong docs này.
