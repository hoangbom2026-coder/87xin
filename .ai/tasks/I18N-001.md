## 1. Scope — Files bị ảnh hưởng

```
apps/frontend-web/src/i18n/locales/en.json   ← PHẢI VIẾT LẠI bằng tiếng Anh
apps/frontend-web/src/i18n/locales/vi.json   ← GIỮ NGUYÊN nội dung (đây là bản VI chuẩn)
libs/i18n/locales/en.json                    ← MỞ RỘNG để sync với apps
libs/i18n/locales/vi.json                    ← MỞ RỘNG để sync với apps
```

**Không chỉnh sửa:**
- `apps/frontend-web/src/i18n/LanguageContext.tsx` (logic đúng, không cần thay đổi)
- Bất kỳ file TSX/TS nào consume `t()` (key path không đổi)

---

## 2. Nguyên tắc chuẩn hóa (SOURCE OF TRUTH)

1. **`vi.json` = nguồn gốc thật** — giữ nguyên làm reference
2. **`en.json` = dịch 1:1 sang tiếng Anh** — CÙNG key path, KHÁC value (tiếng Anh)
3. **Structure phải identical** — cùng namespace, cùng key depth, không thêm/bớt key
4. **Xóa `"vi-VN"` namespace** khỏi cả 2 file (không có component nào dùng key này)
5. **Dịch hết placeholder stubs** — không để value kiểu `"Buildcasinotext"` hay `"Vi-vn"`
6. **libs/i18n** chứa translations **dùng chung** cho nhiều apps — phải đồng bộ keys với apps locale
